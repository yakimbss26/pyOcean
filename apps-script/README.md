# 작품 접수 서버 설치 (선생님용, 처음 한 번)

GitHub 계정이 없는 학생도 갤러리 사이트의 "작품 내기" 페이지에서 작품을 낼 수 있게, 선생님 Google 계정의 시트와 드라이브에 작품을 받아 두는 장치입니다. 10분 정도 걸립니다.

1. Google 드라이브에서 새 구글 시트를 만들고 이름을 `pyOCEAN 작품 접수`로 바꿉니다.
   - 학교 Google Workspace 계정은 "링크가 있는 모든 사용자" 공유가 막혀 있을 수 있으니 개인 Gmail 계정을 권장합니다.
2. 시트 메뉴 확장 프로그램 → Apps Script를 엽니다.
3. 원래 있던 코드를 모두 지우고 이 폴더의 `Code.gs` 내용을 통째로 붙여넣은 뒤 저장(디스크 아이콘)합니다.
4. 위쪽 함수 선택에서 `setup`을 고르고 실행을 누릅니다.
   - 권한 검토 → 내 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용 (내가 만든 스크립트라 괜찮습니다)
   - 시트에 `작품` 탭과 머리줄이, 드라이브에 `pyOCEAN 작품 사진` 폴더가 생깁니다.
5. 오른쪽 위 배포 → 새 배포 → 유형 선택 톱니 → 웹 앱
   - 다음 사용자 인증 정보로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자
   - 배포를 누르고 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. GitHub 저장소의 `config.js`를 열어 연필 아이콘으로 고치고, 따옴표 안에 그 URL을 붙여넣은 뒤 Commit changes를 누릅니다.
   ```js
   window.PYOCEAN_API = "https://script.google.com/macros/s/여기/exec";
   ```
7. 1~2분 뒤 갤러리의 "작품 내기"에서 시험으로 하나 내 보고, 시트에 줄이 생기는지 확인합니다.

## 작품 게시하기

- 학생이 내면 시트에 한 줄이 추가되고 `게시` 칸은 비어 있습니다.
- 내용과 사진 주소를 확인하고 `게시` 칸에 체크하면 갤러리에 나타납니다 (새로고침하면 바로).
- 내리려면 체크를 끄면 됩니다. 오타는 시트에서 바로 고쳐도 됩니다.
- 사진은 드라이브의 `pyOCEAN 작품 사진` 폴더에 쌓입니다.

## 코드를 고쳤을 때

Apps Script 코드를 바꿨다면 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 눌러야 반영됩니다. URL은 그대로라 `config.js`는 다시 고칠 필요가 없습니다.

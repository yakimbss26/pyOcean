내 시뮬레이터를 인터넷 주소로 만들기

manus로 만든 HTML 파일은 지금 내 컴퓨터에만 있어요. GitHub Pages에 올리면 https://아이디.github.io/저장소이름/ 같은 주소가 생기고, 친구들이 갤러리의 바로가기 버튼으로 내 작품을 열 수 있어요. 따라 하는 데 10분이면 충분해요.

준비물

  • GitHub 계정github.com에서 가입. 아이디가 주소에 들어가니 영문으로 기억하기 쉽게 정해요.
  • 내 시뮬레이터 HTML 파일manus에서 받은 .html 파일 하나 (예: 수해 경보기, 스마트 가로등)
  • 크롬 브라우저센서 연결 시험은 크롬에서 해요.
파일 하나로 만들었는지 확인특강 프롬프트처럼 "단일 HTML 파일", "외부 파일 없이" 조건으로 만든 파일이어야 그대로 올라가요. 이미지나 CSS 파일이 따로 있다면 함께 올려야 해요.

1새 저장소 만들기

저장소(repository)는 작품 하나를 담는 폴더라고 생각하면 돼요.

  1. GitHub 로그인 후 오른쪽 위 + → New repository를 눌러요.
  2. Repository name에 영문 소문자로 이름을 적어요. 이 이름이 주소 끝에 붙어요. pyocean-flood
  3. Public을 골라요. Private이면 무료 계정에서는 Pages 주소가 생기지 않아요.
  4. Add a README file을 체크하고 Create repository를 눌러요.
이름 짓기띄어쓰기 대신 하이픈(-)을 써요. 한글, 대문자, 공백은 피해요. 예: pyocean-flood, smart-streetlight, marine-barrier

2HTML 파일 올리기

둘 중 편한 방법 하나만 하면 돼요. 가장 중요한 건 파일 이름을 index.html로 하는 거예요. 그래야 주소만 열어도 작품이 바로 나와요.

방법 A · 파일 끌어다 놓기

  1. 저장소 화면에서 Add file → Upload files
  2. 내 HTML 파일을 화면에 끌어다 놓아요.
  3. 올리기 전에 내 컴퓨터에서 파일 이름을 index.html로 바꿔 두면 편해요.

방법 B · 코드 붙여넣기

  1. Add file → Create new file
  2. 이름 칸에 index.html 을 정확히 적어요.
  3. manus가 준 코드를 처음부터 끝까지 전부 복사해 붙여넣어요.

3커밋(저장)하기

화면 아래(또는 오른쪽 위)의 초록색 Commit changes를 눌러요. 커밋은 "지금 이 상태로 저장"이라는 뜻이에요. 메시지는 그대로 둬도 괜찮아요.

저장소 첫 화면에 README.md와 index.html 두 파일이 보이면 성공이에요.

4GitHub Pages 켜기

  1. 저장소 위쪽 메뉴에서 Settings를 눌러요.
  2. 왼쪽 메뉴에서 Pages를 눌러요.
  3. Build and deployment의 Source가 Deploy from a branch인지 확인해요.
  4. Branch에서 main, 폴더는 / (root)를 고르고 Save를 눌러요.

5내 작품 주소 확인

1~2분 기다린 뒤 Pages 화면을 새로고침하면 위쪽에 Your site is live at 과 함께 주소가 나와요. Visit site를 눌러 열어 봐요.

https://내아이디.github.io/저장소이름/

예: 아이디가 bsshs-kim, 저장소가 pyocean-flood이면 https://bsshs-kim.github.io/pyocean-flood/

6센서로 시험하기

주소로 연 페이지도 특강 때처럼 내 컴퓨터의 ESP32 대시보드 프로그램을 통해 센서 값을 받아요.

  1. 컴퓨터에서 ESP32 대시보드 프로그램을 켜고 보드를 USB(J2 PROG 포트)로 연결해 연결을 눌러요.
  2. 크롬에서 내 작품 주소를 열고 위쪽의 ws://localhost:9001 접속 버튼을 눌러요.
  3. 수위 센서에 물티슈를 대거나, 조도 센서를 손으로 가리거나, 초음파 센서 앞에 손을 대서 화면이 바뀌는지 봐요.
키트가 없는 친구도 볼 수 있어요센서가 연결되지 않은 컴퓨터에서는 화면 모양만 보여요. 그래서 갤러리에는 작동하는 모습을 캡처하거나 짧은 영상으로 함께 올려요.

7갤러리에 제출하기

  1. 브라우저 주소창의 내 작품 주소를 복사해요.
  2. Claude 작품 갤러리를 열고 작품 제출 탭으로 가요.
  3. 작품 링크 칸에 주소를 붙여넣고, 학번 이름, 작동 화면, 설명을 채워 갤러리에 게시하기를 눌러요.

문제 해결

404 There isn't a GitHub Pages site here 가 나와요
파일 이름이 정확히 index.html인지(대문자, 띄어쓰기 없이), 저장소가 Public인지, Pages에서 main 브랜치를 Save했는지 확인하고 2분 더 기다려요.
화면은 나오는데 센서 값이 안 움직여요
대시보드 프로그램이 켜져 있고 ESP32가 연결됐는지 확인해요. 크롬에서 열었는지, 페이지의 접속 버튼을 눌렀는지도 봐요. 그래도 안 되면 특강 때처럼 파일을 더블클릭해 열었을 때는 되는지 비교해요.
코드를 고쳤는데 그대로예요
저장소에서 index.html을 누르고 연필 아이콘으로 고친 뒤 Commit changes를 눌러요. 반영까지 1~2분 걸리니 기다렸다가 Ctrl+F5로 새로고침해요.
화면이 하얗게 나와요
코드를 붙여넣다가 앞뒤가 잘렸을 수 있어요. 코드가 <!DOCTYPE html> 또는 <html로 시작해서 </html>로 끝나는지 확인해요. 크롬에서 F12를 눌러 Console의 빨간 에러를 통째로 복사해 manus에게 물어봐도 좋아요.
manus에게 고쳐 달라고 할 때
이 HTML 파일을 GitHub Pages에 올렸더니 아래 문제가 생겼어.
문제: (여기에 증상이나 Console 에러를 그대로 붙여넣기)
조건: 파일 하나(index.html)로 동작하고, mqtt.min.js는 https CDN을 쓰고, ws://localhost:9001 접속 버튼과 구독 토픽은 지금 그대로 유지해 줘.
